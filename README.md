# Задание 1. ООП

## Задача 1

### Текст задачи

Разработать класс с тремя вещественными полями. Создать конструктор копирования.
Разработать метод, приводящий поля к целому типу. Перегрузить метод ToString() для
формирования строки из полей класса. Реализовать дочерний класс (его содержание предложить
самостоятельно и описать в решении: какой содержательный смысл имеют поля; реализовать
конструкторы; предложить и реализовать 2-3 метода). Протестировать все конструкторы и
другие методы базового и дочернего классов.

### Алгоритм решения
1) Базовый класс FloatNumbers
Поля и Свойства:
_number1, _number2, _number3 - поля для хранения чисел.
Number1, Number2, Number3 - позволяют только читать значения (используем get)
Конструкторы:
- По умолчанию: Принимает три числа и записывает их в поля.
- Копирования: Берет данные из другого объекта FloatNumbers и переносит в новый.
Методы:
- CorrectInput(string): Запускает бесконечный цикл, пока пользователь не введет корректное положительное число.
- ConvertToInteger(): Отбрасывает дробную часть у всех чисел.
- ToString(): Перегрузка метода - выводит три числа через пробел.

2) Дочерний класс Parallelepiped 
Наследует три числа от FloatNumbers и интерпретирует их как размеры фигуры.
Свойства (из родителя): Number1 — длина, Number2 — ширина, Number3 — высота.
Конструкторы:
- По умолчанию: принимает три числа и создает фигуру.
- Копирования: создает новый объект на основе уже существующего.
Методы:
- CalculateVolume(): Считает объем (перемножает длину, ширину и высоту).
- CalculateSurfaceArea(): Считает общую площадь всех сторон.
- ToString(): Перегрузка метода - выводит размеры фигуры одной строкой.

# Задание 2. Перегрузка операций

## Задача 1

### Текст задачи

Вычислить расстояние от точки до начала координат. Результат должен быть типа double.

### Алгоритм решения

Класс Point
Поля _x, _y: Координаты точки.
Конструктор: Принимает значения и создает точку.
Методы:
- CorrectInput: Ввод чисел с проверкой на корректность
- CalculateDistance(): Считает расстояние от этой точки до начала координат по формуле Пифагора.
- ToString(): Перегруженный метод для удобного вывода.

### Алгоритм решения

Переруженные методы:
- Унарные операции ++ и --: Увеличивают или уменьшают координату X на единицу.
- Явное приведение (int): Если написать (int)point, программа вернет целую часть координаты X.
- Неявное приведение double: Если передать точку туда, где ожидается дробное число, она автоматически вернет координату Y.
- Бинарный + (Точка + Точка): Считает расстояние между двумя точками.
- Бинарный + (Точка + Число): Сдвигает точку по оси X на указанное число (p + 5 или 5 + p).
